# 题材写作指南

用户明确给出的题材和形式优先。有题目就选合适的路线，混合题材可分别使用相应核查方法。只有用户把选题交给 Agent 且没给方向时，优先推荐一件资料容易查到、可用图文讲清楚的历史事件。

## 历史人物与历史叙事

- 选题可以是人物、事件、制度、器物、地理或时代变化。先写研究问题和可查来源，再立意。先读 [历史案例](history-seeds.md)，必要时查 [历史选题入口](history-topics.md) 和 [古籍索引](public-domain-sources.md)。
- 首句给「谁做了什么，结果有多反常」。可用可证的数字落差或结果前置。第二句缩小问题，比如同一局面下两方为什么做了不同的选择。
- 正文按人物处境、可用选项、关键行动和后果推进。时间线服务问题。选史传正文、注引异说、考古和研究等适合本题的材料，分别标明来源性质。传说、晚出记载和历史推断写进各自的语境。
- 历史画面可选厚涂历史漫画、黑白纪实或历史写实。同镜核对人物年龄、衣冠、发式、器物和建筑，每次换时期都重看角色设定。档案影像和复原图分别标注性质。
- **练习**　先给城门改向的结果，再查城图和修建记录，依次解释地形、使用者和改动后果。

## 科普、知识讲解与教程

- 科普和解释类先给一个能观察到的现象，然后解释机制、适用条件和例外。使用图解、并排对比、逐步揭示或术语卡。保证比喻的对应关系，使用准确单位。
- 教程先说目标、适用版本和准备条件，按实际操作顺序写步骤。说明成功时出现的结果、怎样验证，以及常见失败的表现。能实际核对的步骤以实查结果为准。
- **练习**　用两个水瓶展示同样的倒水动作为什么会有不同结果。先定义装置和观察，再解释能由实验支持的部分。

## 纪录、真实故事与案例

- 从具体事件、一个可核查的发现或一项决定开场。列出时间线和涉及的各方，把亲历、引用、公开记录与推断分开。
- 用能说明前后变化的资料推进。复原、通用示意、配图和当时记录在画面上各自标明。没有发布授权的个人材料可抽象为匿名案例。
- **练习**　追踪一个地方市场的迁址。先呈现变动，再查公告、时间和各方记录，最后交代影响及哪些变化暂时无法归因。

## 书籍改编与问答

- 先读 [书籍问答案例](yushen-seeds.md)，确定原著确实讨论过的问题。按卷章、页码或可定位段落记出处。原著直引、旁白转述、原创举例分别核对。
- 《与神对话》可用「神啊」加直接问题开场，第一段进入主题，之后用一句话交代必要的作者和文本背景。其他书籍按原书结构及用户要求选开头。对话模式按本次要求组织角色，引用核查写在正文之外。
- 做图书推荐时，选与本期内容相邻的简短过渡，书籍信息按实际情况核实。
- **练习**　围绕一个生活里能说出口的冲突提问，先定位原著段落，再找一个明确标为旁白举例的场景落地。

## 原创故事与虚构

- 建立本期设定表，写清主角目标、限制、行动、后果。开头给触发事件，正文沿选择推进，结尾回收已埋下的细节或冲突。
- 同一人物、装备、空间和规则保持连续。如果采用伪纪录片陈述方式，应在作品信息里标明虚构性质。借用真实历史背景时，另核对用来支撑年代感的细节。
- **练习**　主角收到一张只能使用一次的车票。先说明限制，再让一次犹豫改变可选路线，最后通过一个决定收束。
