# 书籍问答案例

以下问题是写作练习，可以用于《与神对话》或其他书籍的选题。每个问题都要先核对当前书目是否确实讨论过。涉及原著人物的观点时，记录卷章、页码或可定位段落。

| 练习题 | 开场角度 | 结构练习 |
| --- | --- | --- |
| 劝一个人改变，有没有边界？ | 用一则具体的生活冲突直接提问 | 对方的选择 → 自己能承担的部分 → 回扣边界 |
| 听懂一个人以后，还能不同意吗？ | 把理解与同意放在同一句 | 解释两个动作 → 找原著依据 → 用日常场景落地 |
| 既然结果不确定，为什么还要作决定？ | 从一个被推迟的决定切入 | 犹豫的原因 → 能判断的条件 → 选择之后的责任 |
| 道歉以后，还能要求别人原谅吗？ | 把两个人的选择并列 | 道歉的动机 → 对方的决定 → 能做的后续行动 |
| 做出承诺后，什么时候可以改变计划？ | 先摆出一次临时变动的结果 | 承诺的目标 → 条件变化 → 诚实说明与重新协商 |
| 善意怎样避免给别人添负担？ | 从好意造成意外结果切入 | 动机 → 对方的需求 → 一次有边界的帮助 |
| 回顾一件后悔的事，需要先评价自己吗？ | 从回忆中的一个动作切入 | 行为和结果 → 当时掌握的信息 → 现在可以做什么 |

出稿时另附出处表。旁白的举例单独标注，读者能清楚看出哪些是原书观点。
