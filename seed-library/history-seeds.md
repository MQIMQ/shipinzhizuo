# 历史叙事案例

这些案例是新的写作练习。用它们选择结构和镜头，制作历史成片时把练习设定换成本期能核对的史料。

| 练习 | 钩子 | 正文结构 | 需要核对的材料 |
| --- | --- | --- | --- |
| 商队绕路 | 为何有人主动选了更远的路？ | 地图上的最短路 → 当时的阻碍 → 补给与关口 → 实际路线 | 同时期地图、关隘位置和交通条件 |
| 城门改向 | 一道城门的位置为什么改了？ | 旧城图 → 修建原因 → 两种方案 → 变化后的通行 | 城图、修建记录、地形与使用年份 |
| 文书改判 | 把判决作为开场 | 判决 → 关键文书 → 堂上争点 → 结局 | 文书是否齐全、记录人的角色、案件处理结果 |
| 无名器物 | 一件不起眼的器物揭示一种日常活动 | 出土环境 → 物件痕迹 → 相同器物对比 → 可支持的解释 | 出土记录、年代、使用痕迹与研究争议 |
| 船只改道 | 两份记载为什么给出不同的航线？ | 两份路线并排 → 记录者及用途 → 季节或港口条件 → 已知结论 | 原始记录、季节、地名沿革及版本差异 |
| 账簿数字 | 同一批物资，出库和入库为何不一致？ | 数字差异 → 单位换算 → 转运和损耗 → 原因能证实到什么程度 | 当时的单位、账簿口径、运输记录 |

分镜按线索推进。地图、文书、器物都可先拍全景，再突出能支持当前一句口播的细节。复原画面注明其性质。
