# 选题与案例

选题、写稿或改稿前，先读取 [写作 DNA](writing-dna.md)，再读对应的 [题材写作指南](editorial-routes.md)。已有题目时按题材推进。只有把选题交给 Agent 且未指定方向时，优先推荐历史叙事。

| 文件 | 用途 |
| --- | --- |
| [写作 DNA](writing-dna.md) | 通用选题、钩子、结构、口播和核查 |
| [题材写作指南](editorial-routes.md) | 历史、科普与教程、真实故事、书籍改编、原创故事 |
| [历史案例](history-seeds.md) | 6 条历史叙事练习 |
| [书籍问答案例](yushen-seeds.md) | 7 条书籍改编练习 |
| [历史选题入口](history-topics.md) | 按问题查找可能相关的古籍 |
| [古籍索引](public-domain-sources.md) | 公共领域文献及叙事参考 |

先从练习里选方法，再对照实际史料或原著写稿。按 [主技能](../SKILL.md) 提交本期出处表和事实核查。
