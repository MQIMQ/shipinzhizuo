# 爆款种子库（seed-library）

选题不用从零想。先翻种子，再动手。

## 怎么用

1. 先定赛道：历史线翻 `history-seeds.md` 和 `history-topics.md`；书籍改编线翻 `yushen-seeds.md`。
2. 挑一条种子，照着它的钩子套路和结构写新稿，不要照抄它的原文。
3. 写稿前按 SKILL.md 第 2 步建出处表：书籍线建脚本出处表，历史线建史料出处表。种子里的史料落点是起点，不是免检牌。
4. 每条种子都标了数据或状态。标了播放数的，是跑出过的数据；标了"未统计"或"待审"的，是还没跑出数据的稿子或成片，复用时看结构不看成绩。

## 钩子套路只有四个

种子库里的钩子只用 SKILL.md 里已有的四个方向，不另发明：

- 直接提问：把观众心里的问题原样问出来，不绕弯子。
- 数字对比：用两组真实数字制造落差，数字必须是核实过的。
- 结果前置：先把结局或成绩摆出来，再倒回去讲怎么来的。
- 反常场景：先给一个和常识不符的画面，再揭晓为什么。

## 来源规则（死规矩）

- 种子只来自两样东西：李奥号自己的成片和数据，以及公共史料（正史、传世文献、公版原著、考古与传世文献记载）。
- 每条种子都能对应到下面来源清单里的具体文件或数据，列不出来的不写。
- 不抄任何第三方的稿子原文、DNA 文字、钩子例句。题目名（人物/事件名）是史实，不是任何人的原创，只列题目名的清单见 `corpus-topics.md`，用前必须先核查出处、自己从公版史料出发写。
- 本库与任何第三方的语料库、钩子库、DNA 写法无关。
