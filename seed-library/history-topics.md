# 历史选题入口

先选一个人、一件物或一次变化，写清要核实的问题。以下书目提供检索起点。

| 方向 | 试写问题 | 初始材料 |
| --- | --- | --- |
| 决策和后果 | 关键人物手中有什么选择？ | 《史记》《资治通鉴》 |
| 同一人物的多种记载 | 哪些情节在不同版本中一致？ | 《三国志》正文及裴注 |
| 城市与交通 | 当时的交通或制度怎样影响个人决定？ | 《旧唐书》《新唐书》《宋史》相关地理和人物条目 |
| 寓言或轶闻 | 作者用这则故事讨论什么？ | 《庄子》《世说新语》 |
| 传说的文本版本 | 同一故事如何被不同记录者讲述？ | 《古事记》等可查古籍，注明传说属性 |

具体链接见 [古籍索引](public-domain-sources.md)，分镜与讲述方法见 [历史案例](history-seeds.md)。
