# 李奥视频工作室（liao-video-studio）

使用者可以自行修改本 skill（改音色、改画幅、改流程都行），改完署名保留“李奥视频工坊”即可；改后的版本责任自负。

做历史人物传记、历史叙事、书籍改编类图文视频的完整流程。主线是历史类，书籍改编（与神对话线）是第二条线。按这套流程，李奥号已经做了 11 期，最高单条 31.8 万播放；第一期全程没提一句“买”，也没做带货口播，卖了 9 本书。

先做一条，再回头改流程。

## 这个 skill 是什么

- 一份完整工作流（`SKILL.md`）：从选题、溯源脚本、确认、配音、配图、分镜、合成、质检到交付，共 10 步。主线是历史类，书籍改编线是第二条线。
- 一个爆款种子库（`seed-library/`）：与神对话 7 条种子 + 历史 6 条种子 + 历史选题清单，全部来自李奥号自己的成片和数据。
- 两个脚本（`scripts/`）：豆包配音 + FFmpeg 合成出片，都是能直接跑的。
- 一份计划示例（`plan.json`）：照着填，就能出片。

成品：旁白 + 分段配图 + 轻动效的长视频（主力 6 分钟左右），历史线默认 9:16 竖版，书籍问答线 3:4（1080x1440），mp4 直接出片，封面剪进片头前 0.5 秒。

## 需要什么

| 东西 | 用途 | 怎么弄 |
|---|---|---|
| Python 3.10 以上 | 跑两个脚本 | 系统自带或官网装 |
| FFmpeg（含 ffprobe） | 合成、校验 | 官网下官方构建，装好确认 `ffmpeg -version` 能跑 |
| 豆包语音 Key | 配音 | 火山引擎控制台开通豆包语音服务，在 API Key 管理里创建 Key |
| 写稿工具 | 写脚本 | Antigravity CLI（`agy`）调 Gemini；不要用 Gemini CLI 的 Google 登录，已验证不可用 |
| 生图工具 | 配图 | Codex 图像生成，模型 gpt-6-luna |

核心流程（步骤 0–10）只需要 Python + FFmpeg + 豆包 Key 就能跑通。

## 怎么装进你的 agent

把整个 `liao-video-studio` 文件夹复制到你 agent 的 skills 目录里，例如：

```bash
cp -r liao-video-studio ~/.codex/skills/liao-video-studio
```

不同 agent 的 skills 目录位置不一样，放进你那个 agent 能读到的 skills 目录就行。装好后直接对 agent 说“用 liao-video-studio 帮我做一条视频”。

## 怎么跑：一条片子四步

### 1. 写脚本（按 SKILL.md 第 0–3 步）

选题、溯源、确认。最重要的一条：书籍线每一规划段落先在原著里找到出处再动笔，原书真说过的话才能标成原话，自己补的衔接一律是旁白口吻；历史线每条断言先在史料里找到出处再动笔，建史料出处表。脚本 + 出处表 + 事实核查表一起确认，没确认不开工。

### 2. 配音（第 4 步）

按段合成，不要一次合成一整篇：

```bash
export DOUBAO_TTS_API_KEY="你的 Key"
python3 scripts/doubao_tts.py --text-file seg1.txt --output seg1.mp3
python3 scripts/doubao_tts.py --text-file seg1.txt --output seg1.mp3 --dry-run  # 只核验，不花钱
```

- 默认音色是云舟。想换音色：`--speaker zh_male_liufei_uranus_bigtts`（刘飞 2.0）、`zh_female_xiaohe_uranus_bigtts`（小何 2.0）、`zh_female_vv_uranus_bigtts`（Vivi）。只有这四个预置音色，不克隆声音。
- Key 也可以用 `--key-stdin` 从标准输入传（输完不留记录），绝不要把 Key 写进文件、代码或聊天。
- 每段合成完立刻用 ffprobe 量出真实秒数并记下来，再按顺序拼成完整旁白。

### 3. 配图和分镜（第 6–7 步）

每段 4 张图，按起承转合递进。先出分镜表和 1 张测试图，确认长相和风格后再批量生成。人物描述全片同一份；图里不带任何文字；单人旁白不出现正对镜头张嘴说话的脸。

### 4. 合成出片（第 8–10 步）

按分段时长写一份 `plan.json`（照着本 skill 根目录的示例填），然后：

```bash
python3 scripts/render.py --plan plan.json --output final.mp4
python3 scripts/render.py --plan plan.json --check-only   # 只核验计划，不渲染
```

- 输出就是 mp4（h264 + aac），不用进剪映。
- 封面填进 plan.json 的 `cover` 字段，会占片头前 0.5 秒，旁白照常播放，总时长不变。第一镜的时长会自动减 0.5 秒，所以第一镜至少要 0.5 秒以上。
- 每张图缓慢推近，图与图之间 0.8 秒交叉淡化，不烧录字幕。
- 出片后立刻用 ffprobe 核对总时长、分辨率、帧率、音视频流是否齐全；总时长和音频对不上超过 1 秒，先查原因再交付。

## 常见问题

**配音报鉴权或额度错误**：停在配音这一步，先去控制台核对 Key 和服务开通状态，不要反复重试（失败也可能计费）。

**成片比音频短 / 长超过 1 秒**：多半是某段时长记错了，对照第 4 步的分段时长表逐段查，不要直接交付。

**切点处人物突然换姿势**：用前一镜的末帧做参考，重新生成后一镜，再复查这个切点，不要整段推倒。

**图里出现乱码文字**：不要让 AI 在图里写字。图内零文字，标题走封面排版。

**文案被指“书里根本没这话”**：回第 2 步，逐段补出处或改成旁白口吻。没有出处的段落，要么删掉，要么改成明确的旁白讨论，永远不要标成原书原话。

## 三条铁律（再提醒一次）

1. 脚本没确认，不配音、不配图。
2. 音频定了就不改，后面迁就音频。
3. 出错只重做出错的那一段，不整批推倒。
